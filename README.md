# Вгадай слово

## Вимоги
1. Гравець вводить літери, намагаючись відгадати слово.
2.  Після кожної спроби комп’ютер повідомляє, які букви вгадані правильно.
3. Неправильна літера зменшує життя.
4. Гра завершується перемогою якщо слово вгадано до втрати останнього життя.
5. Можливість повернутися в меню посеред гри.
   Підтримка різних типів гравців:
   - Дитина: більше життів.
   - Бог: одне життя.
   - AI-гравець: самостійно вгадує літери.
## Модульний дизайн
- Інтерфейс `game.Game` описує загальний функціонал.
- Клас `WordGuessGame` реалізує ігрову логіку.
## Модульна структура
1. **Інтерфейс `game.Game`**
    - Визначає загальну структуру для ігор:
        - `start()` – розпочати гру.
        - `play()` – основний ігровий цикл.
        - `checkWinner()` – перевірка умов завершення гри.
        - `printBoard()` – виведення стану гри.

2. **Клас `WordGuessGame`**
    - Реалізує логіку гри "Вгадай слово".
    - Відповідає за:
        - Збереження стану гри (слово, кількість життів, використані літери).
        - Обробку користувацького вводу.
        - Визначення умов перемоги чи поразки.

## Логіка гри
1. **Ініціалізація гри**
    - Випадковий вибір слова.
    - Початкові значення:
        - Життя: `8`.
        - Список використаних літер: порожній.
        - Стан слова (масив `"-"`).

2. **Ігровий цикл**
    - Користувач вводить літери.
    - Якщо літера правильна – вона розкривається.
    - Якщо літера неправильна – зменшується кількість життів.
    - Кінець гри:
        - Відгадано всі літери – перемога.
        - Життя закінчилися – поразка.
